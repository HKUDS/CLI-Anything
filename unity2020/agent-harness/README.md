# Unity Legacy CLI

Upstream harness for **Unity Legacy CLI** inside the CLI-Anything monorepo. The command is `unity-legacy-cli`; the monorepo layout and CLI-Hub entry keep the canonical `unity2020` slug and the `skills/cli-anything-unity2020/SKILL.md` skill identity.

See the [Unity Legacy CLI guide](cli_anything/unity2020/README.md) for installation, compatibility, command groups and tests. [UNITY2020.md](UNITY2020.md) describes the bridge design. The [standalone repository](https://github.com/key-zxy/unity-legacy-cli) distributes the same bridge under the same command name.
