# CLI-Anything fzf harness

This directory is the installable source package for the fzf 0.74.5 harness.
The complete operator and agent guide is
[`cli_anything/fzf/README.md`](cli_anything/fzf/README.md), the architecture and
coverage record is [`FZF.md`](FZF.md), and the observed validation procedure is
[`cli_anything/fzf/tests/TEST.md`](cli_anything/fzf/tests/TEST.md).

Install locally from this directory with `python -m pip install .` or use an
isolated editable development install with `python -m pip install -e '.[test]'`.
The installed command is `cli-anything-fzf`.
